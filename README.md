# 📸 TasveerWorld

TasveerWorld is a modern image gallery web application inspired by platforms like Freepik and Unsplash. It allows users to browse, search, upload, download, and manage high-quality images with a clean and responsive user interface.

---

## 🚀 Live Demo

👉 https://tasveerworld.vercel.app/

## ✨ Features

- 🔍 Search images by title, category, author, or tags
- 🗂 Category-wise image filtering
- 🖼 Beautiful masonry image gallery
- 📂 Collections section
- 📤 Upload images
- ☁ Cloudinary image hosting
- 🔥 Firebase Firestore database
- ⚡ Real-time image synchronization
- 💾 LocalStorage backup support
- 👤 Admin Login
- 🗑 Delete uploaded images
- ⬇ Download images
- 🖼 Similar image recommendations
- 📱 Fully responsive design
- 🌙 Modern Freepik-inspired UI

## ⚙ Installation

Clone the repository

```bash
git clone https://github.com/yourusername/TasveerWorld.git
```

Go to project folder

```bash
cd TasveerWorld
```

Open

```text
index.html
```

No additional installation is required.

## 🔥 Firebase Configuration

Replace your Firebase configuration inside

```javascript
const firebaseConfig = {
  apiKey: "...",
  authDomain: "...",
  projectId: "...",
  storageBucket: "...",
  messagingSenderId: "...",
  appId: "..."

```
